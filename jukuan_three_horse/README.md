## 🔧 核心功能模块

### 1️⃣ ATR动态止损模块

**原理**：
ATR（Average True Range）平均真实波幅，衡量价格波动性。

**计算公式**：
```
TR = MAX(最高价-最低价, |最高价-前收盘|, |最低价-前收盘|)
ATR = N日内TR的平均值
持仓最高价 = MAX(成本价, 前收盘价, 每日更新最高价)
止损价 = 持仓最高价 - ATR × 倍数
```

**止损策略**：
- **亏损状态**：使用固定止损（-7%）
- **盈利状态**：使用ATR跟踪止损
  - 🔧 **重要修复**：使用持仓期间最高价（不是历史最高价）
  - 避免刚买入就因历史高价而触发止损
- **多级盈利保护**：
  - 盈利20%：止损提高到成本价
  - 盈利50%：止损提高到成本价+20%
  - 盈利100%：继续跟踪或全部止盈

**差异化配置**：

| 策略 | ATR周期 | ATR倍数 | 盈利保护点 |
|------|---------|---------|-----------|
| 小市值 | 14天 | 2.8 | 20%/50%/100% |
| ETF反弹 | 10天 | 2.0 | 10%/20%/50% |
| ETF轮动 | 10天 | 2.0 | 10%/30%/80% |
| 白马攻防 | 14天 | 2.5 | 15%/30%/60% |
| 红利策略 | 20天 | 3.0 | 10%/25%/50% |

**检查频率**：
- 09:31, 10:00, 14:50（每日3次）

**开关控制**：
```python
g.enable_atr_stoploss = True   # 开启ATR止损
g.atr_check_times = ["09:31", "10:00", "14:50"]  # 检查时间
```

### 📖 ATR止损实例详解

以**小市值策略**为例，详细说明ATR止损的完整流程：

#### **场景设置**
- 股票代码：`000001.XSHE`
- 买入成本价：**10.00元**
- 持仓数量：1000股
- ATR参数：周期14天，倍数2.8
- 盈利保护点：20%/50%/100%

#### **第一阶段：ATR计算**

假设获取该股票最近14天的价格数据：

| 日期 | 收盘价 | 最高价 | 最低价 | TR值 | 计算说明 |
|------|--------|--------|--------|------|---------|
| T-13 | 9.80 | 10.00 | 9.60 | 0.40 | max(0.40, |10.00-9.80|=0.20, |9.60-9.80|=0.20) = 0.40 |
| T-12 | 9.90 | 10.10 | 9.75 | 0.35 | max(0.35, |10.10-9.80|=0.30, |9.75-9.80|=0.05) = 0.35 |
| T-11 | 10.20 | 10.40 | 9.95 | 0.45 | max(0.45, |10.40-9.90|=0.50, |9.95-9.90|=0.05) = 0.50 |
| ... | ... | ... | ... | ... | ... |
| T-1 | 10.30 | 10.50 | 10.10 | 0.40 | ... |
| T-0 | 10.50 | 10.80 | 10.20 | 0.60 | max(0.60, |10.80-10.30|=0.50, |10.20-10.30|=0.10) = 0.60 |

**ATR计算**：
```
ATR = (0.40 + 0.35 + 0.50 + ... + 0.40 + 0.60) / 14
ATR = 5.60 / 14 = **0.40元**
```

---

#### **第二阶段：止损价格计算（分3种情况）**

---

##### **情况1：亏损状态（价格下跌）**

**假设当前价格**：**9.50元**
**当前盈亏**：(9.50 - 10.00) / 10.00 = **-5%** ❌

**止损逻辑**：
```python
if current_return <= 0:  # 亏损状态
    stoploss_price = avg_cost * (1 - 0.07)  # 固定止损7%
    stoploss_price = 10.00 × 0.93 = **9.30元**
```

**判断**：
- 当前价格：9.50元
- 止损价格：9.30元
- 比较：9.50 > 9.30 ✅ **未触发止损**

**说明**：亏损时使用固定止损（-7%），不使用ATR，避免过度频繁止损。

---

##### **情况2：盈利状态-刚开始盈利**

**假设当前价格**：**11.00元**
**当前盈亏**：(11.00 - 10.00) / 10.00 = **+10%** ✅
**持仓期间最高价**：**11.20元**

**止损逻辑**：
```python
else:  # 盈利状态
    # 获取持仓期间最高价
    highest_price = max(历史最高价, 成本价) = 11.20元
    
    # ATR跟踪止损
    stoploss_price = highest_price - atr × multiplier
    stoploss_price = 11.20 - 0.40 × 2.8 = 11.20 - 1.12 = **10.08元**
    
    # 检查多级盈利保护
    if current_return >= 0.20:  # 盈利20%
        stoploss_price = max(stoploss_price, 成本价×1.00)
    if current_return >= 0.50:  # 盈利50%
        stoploss_price = max(stoploss_price, 成本价×1.20)
    if current_return >= 1.00:  # 盈利100%
        stoploss_price = max(stoploss_price, 成本价×1.50)
```

**多级盈利保护判断**：
- 盈利10% < 20%：未达到任何盈利保护点
- 最终止损价：**10.08元**（ATR跟踪止损）

**判断**：
- 当前价格：11.00元
- 止损价格：10.08元
- 比较：11.00 > 10.08 ✅ **未触发止损**

**说明**：刚开始盈利时，使用ATR跟踪止损，给股票波动空间。

---

##### **情况3：盈利状态-达到盈利保护点**

**假设当前价格**：**12.00元**
**当前盈亏**：(12.00 - 10.00) / 10.00 = **+20%** ✅
**持仓期间最高价**：**12.30元**

**止损逻辑**：
```python
else:  # 盈利状态
    highest_price = 12.30元
    
    # ATR跟踪止损
    atr_stoploss = 12.30 - 0.40 × 2.8 = 12.30 - 1.12 = 11.18元
    
    # 多级盈利保护
    # 盈利20%，保护盈利
    if current_return >= 0.20:  # 20% ≥ 20%
        profit_stoploss = 成本价 × 1.00 = 10.00 × 1.00 = 10.00元
        
        # 取两者的较大值
        stoploss_price = max(11.18, 10.00) = **11.18元**
```

**判断**：
- 当前价格：12.00元
- 止损价格：11.18元
- 比较：12.00 > 11.18 ✅ **未触发止损**

**说明**：达到20%盈利时，盈利保护会将止损价提高到成本价（10.00元），但ATR跟踪止损更高（11.18元），所以最终使用ATR跟踪止损。

---

##### **情况4：盈利状态-大幅上涨后**

**假设当前价格**：**15.00元**
**当前盈亏**：(15.00 - 10.00) / 10.00 = **+50%** ✅
**持仓期间最高价**：**15.50元**

**止损逻辑**：
```python

```

**判断**：
- 当前价格：15.00元
- 止损价格：14.38元
- 比较：15.00 > 14.38 ✅ **未触发止损**

**说明**：盈利50%时，盈利保护提高到成本+20%（12.00元），但ATR跟踪止损更高（14.38元），仍使用ATR跟踪止损，让利润充分奔跑。

### 🎯 ATR止损核心优势

| 传统止损 | ATR动态止损 |
|---------|-------------|
| 固定百分比（如-7%） | 自适应市场波动 |
| 波动大时容易频繁止损 | 波动大时止损更宽 |
| 波动小时止损太宽松 | 波动小时止损更紧 |
| 无法区分盈利/亏损 | 分级保护，让利润奔跑 |

**关键特点**：
1. **自适应波动**：ATR越大，止损距离越宽；ATR越小，止损距离越窄
2. **分级保护**：盈利越多，止损线越高，锁定收益
3. **跟踪止损**：价格创新高时，止损线也跟着上移
4. **避免过早止盈**：不会在短期波动中轻易卖出

### 2️⃣ 市场情绪择时模块

**原理**：
综合评估市场情绪，在市场极端情况下调整仓位。

**评分维度**（3个维度，加权计算）：

| 维度 | 权重 | 计算方法 |
|------|------|---------|
| 恐慌指数 | 40% | (跌停家数 / 总家数) × 100 |
| 北向资金 | 40% | 沪深300连续下跌天数（代理指标） |
| 大盘涨跌家数 | 20% | 上涨家数 / 总家数 |

**说明**：
- 🔧 **北向资金**：由于聚宽平台限制，使用沪深300涨跌作为资金流向代理指标
- ❌ **新股破发率**：已删除该指标（IPO数量少，参考价值低）

**仓位调整规则**：

| 情绪评分 | 仓位比例 | 决策说明 |
|---------|---------|---------|
| < 20 | 0% | 极度恐慌：清仓空仓 |
| 20-40 | 50% | 恐慌：减仓至50% |
| 40-60 | 100% | 中性：保持正常仓位 |
| ≥ 60 | 100% | 强势：正常交易 |

**应用方式**：
1. **买入资金调整**：各策略买入金额 × 仓位比例
2. **暂停调仓**：仓位 < 50% 时，停止新买入

**执行时间**：

```python
g.enable_technical_filters = True  # 开启技术指标筛选
```

### 4️⃣ 动态权重优化模块

**原理**：
基于历史表现，每月动态调整各策略的资金分配权重。

**优化目标**：
VASR（Variance-Adjusted Sharpe Ratio）方差调整夏普比率

**约束条件**：
- 权重总和 = 1
- 单个策略权重变动 < 10%
- 各策略权重 > 0

**执行时间**：
- 每月执行一次

**开关控制**：
```python
g.fixed_weight_mode = False  # False=动态优化，True=固定权重
```

### 5️⃣ 大盘顶背离检查（小市值策略）

**原理**：
检测大盘指数（399101.XSHE）是否出现顶背离信号。

**顶背离定义**：
- 价格创新高，但指标未创新高
- MACD、RSI等指标出现背离

**触发条件**：
- 连续10天检测
- 出现顶背离信号

**处理方式**：
- 清仓小市值持仓
- 买入防御性ETF

**开关控制**：
```python
g.DBL_control = True  # 开启顶背离控制
```

## 🐛 常见问题

### Q1：策略不执行买入？

**可能原因**：
1. 市场情绪评分过低（< 50）
2. 技术指标筛选过滤
3. 资金不足
4. 选股条件过严

**解决方法**：
- 检查日志中的情绪评分
- 关闭技术指标筛选：`g.enable_technical_filters = False`
- 放宽选股条件

### Q2：回测亏损严重？

**可能原因**：
1. 回测时间包含极端行情
2. 参数配置不合理
3. ATR止损倍数过小

**解决方法**：
- 缩短回测时间，避免极端行情
- 参考 `TUNING_GUIDE.md` 调整参数
- 增大ATR倍数

### Q3：实盘与回测差异大？

**可能原因**：
1. 滑点影响
2. 流动性不足
3. 冲击成本

**解决方法**：
- 减少调仓频率
- 选择流动性好的标的
- 降低单次交易金额
