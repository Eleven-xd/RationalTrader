# 三驾马车策略 - 优化版使用说明

## 二、优化功能总览

### 2.1 ATR动态止损

**核心优势**：
- 自适应个股波动性，避免震荡市频繁止损
- 实现趋势跟踪，让利润奔跑
- 多级盈利保护，锁定收益

**策略差异化配置**：

| 策略 | ATR周期 | ATR倍数 | 盈利保护点 | 特点 |
|------|---------|---------|-----------|------|
| 小市值 | 14天 | 2.0 | 20%/50%/100% | 波动大，留更多空间 |
| ETF轮动 | 10天 | 1.5 | 10%/30%/80% | 波动小，及时止损 |
| ETF反弹 | 10天 | 1.5 | 10%/20%/50% | 短期反弹，严格止损 |
| 白马攻防 | 14天 | 2.0 | 15%/30%/60% | 中长期，稳健保护 |
| 红利策略 | 20天 | 2.5 | 10%/25%/50% | 价值投资，宽止损 |

**止损逻辑**：
1. 亏损状态：使用7%固定止损（保底）
2. 盈利状态：使用ATR跟踪止损（动态）
3. 多级保护：盈利20%后保本，50%后锁定20%利润

### 2.2 市场情绪择时

**综合指标**：
- 恐慌指数（跌停家数比例）- 权重30%
- 北向资金流向（连续净流出天数）- 权重30%
- 新股破发率 - 权重20%
- 大盘涨跌家数比例 - 权重20%

**择时决策**：
- 评分 < 20：清仓空仓
- 评分 < 40：减仓至50%
- 评分 ≥ 40：正常交易

### 2.3 技术指标筛选

**小市值策略新增筛选**：
- RSI指标：20 < RSI < 80（避免超买超卖）
- 均线多头排列：5日均线 > 20日均线
- 突破新高：创60日新高（优先）

## 三、使用方法

### 3.1 在聚宽平台上使用

**步骤1**：上传必要文件到聚宽
```
1. three_horse_optimized_full.py
2. atr_service.py
3. market_sentiment.py
```

**步骤2**：创建策略
- 在聚宽平台创建新策略
- 将 three_horse_optimized_full.py 的内容复制到策略编辑器
- 确保同时上传 atr_service.py 和 market_sentiment.py

**步骤3**：设置回测参数
```
起始日期：2023-01-01
结束日期：当前日期
初始资金：1000000（或其他）
```

**步骤4**：运行回测
- 点击"运行回测"
- 观察回测结果

### 3.2 功能开关配置

在 `initialize()` 函数中可以配置功能开关：

```python
# ATR动态止损开关
g.enable_atr_stoploss = True  # 启用ATR动态止损
g.atr_check_times = ["09:31", "10:00", "10:30", "14:50"]  # 检查时间

# 市场情绪择时开关
g.enable_market_sentiment = True  # 启用市场情绪择时
g.market_sentiment_threshold = 40  # 情绪阈值

# 技术指标筛选开关（小市值策略）
g.enable_technical_filters = True  # 启用技术指标筛选
```

### 3.3 参数调优建议

**ATR参数调优**：
- 小市值策略：
  - 波动大的市场：ATR周期延长至20天，倍数增至2.5
  - 波动小的市场：ATR周期缩短至10天，倍数减至1.8

- ETF轮动策略：
  - 激进风格：倍数1.3（及时止损）
  - 稳健风格：倍数1.8（给更多空间）

**市场情绪阈值调优**：
- 保守：阈值提高到50
- 激进：阈值降低到30

**技术指标筛选调优**：
- 可调整RSI范围（如15-75）
- 可调整均线周期（如5日和60日）

## 七、常见问题

### Q1: ATR止损和固定止损如何协调？

A: ATR动态止损为主要风控机制，固定止损（9%）作为保底。优先级：
1. 大盘跌幅清仓（最高）
2. ATR动态止损（中）
3. 固定止损（最低）

### Q2: 市场情绪择时如何影响仓位？

A: 根据情绪评分调整各策略的建仓金额：
- 评分 < 40：建仓金额 × 50%
- 评分 < 20：建仓金额 × 0%（清仓）
- 评分 ≥ 40：建仓金额 × 100%（正常）

### Q3: 技术指标筛选只对小市值策略生效吗？

A: 目前技术指标筛选（RSI、均线等）主要应用于小市值策略的选股阶段。其他策略（ETF等）已有自己的技术筛选逻辑（RSRS、动量等）。

### Q4: 如何临时禁用某个优化功能？

A: 在 initialize() 函数中修改对应开关：
```python
# 禁用ATR动态止损
g.enable_atr_stoploss = False

# 禁用市场情绪择时
g.enable_market_sentiment = False

# 禁用技术指标筛选
g.enable_technical_filters = False
```

### Q5: 优化版是否完全兼容原版？

A: 优化版保留了原版的所有功能，并在此基础上增加了优化。如果需要完全恢复到原版，可以使用 three_horse_refractor.py 文件。
