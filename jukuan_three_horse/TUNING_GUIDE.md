## 🎯 其他调参选项

### 选项1：关闭市场情绪择时

如果认为市场情绪择时过于保守，可以完全关闭：

```python
g.enable_market_sentiment = False  # 关闭市场情绪择时
```

**优点**：不会因情绪不佳而减仓，保持满仓操作
**缺点**：可能在系统性风险时遭受较大回撤

---

### 选项2：关闭技术指标筛选

如果技术指标筛选过滤了太多优质股票：

```python
g.enable_technical_filters = False  # 关闭技术指标筛选
```

**优点**：增加选股机会，避免错失好股
**缺点**：可能买入超买或技术面不佳的股票

---

### 选项3：动态调整资金分配

启用动态资金分配优化（根据历史表现自动调整权重）：

```python
g.fixed_weight_mode = False  # 启用动态优化（当前已启用）
```

**说明**：系统会每月根据历史表现自动调整各策略的资金分配

---

### 选项4：调整小市值策略版本

```python
g.xsz_version = "v1"  # v1=双市值+行业分散，v2=国九+roa+roe，v3=国九+红利+审计
```

**建议**：
- **v1**：更分散，回撤更小，但收益可能稍低
- **v2**：财务质量筛选，更适合长期
- **v3**：当前版本，平衡型

## ⚠️ 风险提示

1. **激进配置会增加回撤**：ATR倍数增大、止损频率降低都会导致回撤增大
2. **过度优化风险**：参数过于激进可能导致策略在特定市场环境下表现恶化
3. **实盘前务必回测**：任何参数调整都需要经过充分的历史回测验证
4. **逐步调整**：建议先小幅度调整，观察效果后再进一步优化

---

## 🔧 回测建议

1. **多时间段回测**：至少回测3-5年，覆盖牛熊震荡市
2. **参数敏感性测试**：对关键参数进行网格搜索
3. **蒙特卡洛模拟**：评估策略在不同市场环境下的稳定性
4. **滚动窗口回测**：避免前视偏差
